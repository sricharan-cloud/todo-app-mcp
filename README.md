# ToDo App - MCP Assignment

## Overview
This project demonstrates MCP setup and skill-based workflow using a CLI-based ToDo application.

---

## Skills Used

### 1. grill-me
Used to challenge and refine the project idea.

### 2. write-a-prd
Created a Product Requirements Document defining features and flow.

### 3. prd-to-issues
Converted PRD into development tasks.

### 4. tdd
Generated test cases and implementation using Test Driven Development.

### 5. improve-codebase-architecture
Improved structure and scalability of the code.

---

## Features
- Add tasks
- List tasks
- Delete tasks

---

## Run the Project

node todo.js add "Task"
node todo.js list
node todo.js delete 1
